# SimSketch 2D CAD 路线图

> 技术栈将迁移到 WebGPU + TypeScript，并把高性能几何计算下沉到 Rust/Wasm。迁移顺序和边界见 `docs/adr/0001-webgpu-typescript-rust-wasm.md`。下面的阶段顺序不变，但 P0 的代码边界要按 ADR 的目录拆分。

## 1. 定位

SimSketch 不是通用参数化 CAD，也不是 3D 建模器。

目标是把「仿真草图」做成一个**浏览器里能画准、能改准、能交换的 2D 草图工作台**：

1. **画准**：世界坐标、栅格、捕捉、正交、数值输入。
2. **改准**：夹点编辑、属性面板、修剪/延伸/偏移/圆角、尺寸标注。
3. **能交换**：SVG / JSON / DXF，后续可接仿真标注与求解器。

刻意不做：

- 3D 实体建模、装配、工程图出图。
- 第一版不追求完整约束求解器。
- 使用 Vite 构建纯静态站点（`dist/` 可托管到任意静态站点）。
- 不为「像 CAD」堆按钮；每个工具都要有明确的坐标语义和可测试几何。

## 2. 当前基线

已经具备：

- 图元：直线、矩形、圆、三点圆弧。
- 选择：单选、Shift 多选、拖动整体移动。
- 布尔：并集、差集、交集；结果保存为带孔洞和分离块的 MultiPolygon 路径。
- 图层、颜色、透明度、撤销/重做、IndexedDB 草稿。
- 导出：PNG、SVG、JSON。
- 仿真标注：区域、箭头、文字、载荷、待确认事项。
- 测试：`pnpm test`（Vitest）覆盖几何与草稿迁移，`pnpm test:e2e` 跑浏览器冒烟。

当前最大的限制不是「图元种类少」，而是：

- 坐标只有画板单位，没有独立的视口和缩放/平移。
- 所有输入靠鼠标位置，不能输入精确尺寸。
- 没有捕捉，画出来的线不保证端点相接或水平垂直。
- 选中后不能改单个端点/半径，只能整体移动。
- 标注绑定的是绝对坐标，图形移动后标注不跟随。

## 3. 总体阶段

| 阶段 | 主题 | 核心交付 | 完成判据 |
| --- | --- | --- | --- |
| P0 | 精确绘图底座 | 视口、捕捉、正交、数值输入 | 不靠鼠标手感，也能画出指定长度/角度/尺寸 |
| P1 | 编辑能力 | 夹点、框选、属性面板、修剪/延伸/偏移/圆角 | 已画图形能精确改，而不是删了重画 |
| P2 | 尺寸与轻约束 | 线性/半径/角度尺寸；水平/垂直/重合/等长 | 尺寸可驱动图形，至少支持轻量约束子集 |
| P3 | CAD 交换 | DXF 导入/导出（LINE/CIRCLE/ARC/LWPOLYLINE/TEXT/LAYER） | 能进 FreeCAD/AutoCAD 打开，往返不丢基本图层和单位 |
| P4 | 仿真标注绑定 | 标注锚定图元/路径/面，几何移动后标注跟随 | 改图形不再破坏已标注的约束和载荷 |

顺序不能乱：P0 是后面所有编辑和约束的地基；P2 的约束求解必须建立在 P0 的坐标和 P1 的编辑语义上。

## 4. P0：精确绘图底座

### 4.1 视口与坐标系

- 模型坐标继续使用现有画板单位，但把**模型坐标**和**视图变换**拆开。
- 新增临时状态 `viewport = {x, y, zoom}`，不写进项目数据；只把「上次视图」作为本地偏好保存。
- `board.viewBox` 由 viewport 计算，不再用「把内容撑大」的方式自适应。
- 支持：滚轮缩放、触控板双指缩放、空格拖拽平移、`F` 适配全图、`0` 回到 100%。
- 屏幕像素与模型单位互转只放在 `viewport.ts`，所有工具不直接算 CTM。

验收：

- 缩放后绘制、拖动、命中、导出坐标一致。
- 缩放 10% 和 800% 下，端点捕捉阈值都是固定的屏幕像素。

### 4.2 捕捉引擎

新增 `snap.ts`，纯函数，不碰 DOM：

```js
resolveSnap(entities, rawPoint, options) -> {
  point: [x, y],
  type: 'grid' | 'endpoint' | 'midpoint' | 'center' | 'quadrant' | 'intersection' | 'nearest',
  entityId: string | null
}
```

优先级：端点 > 中点 > 圆心 > 象限点 > 交点 > 最近点 > 栅格。

- 阈值按屏幕像素换算成模型单位，缩放时不变。
- 绘制和拖动都要经过同一个捕捉入口。
- 画布上显示捕捉类型的小标记，不显示时不要打扰。
- 正交/极轴：Shift 约束到 45°；可切换固定角度集合（45/90）。
- 画线时同时支持「从已有点开始」和「落到已有点结束」。

验收：

- 任意缩放级别下，画的线和已有端点重合误差小于 0.0001 模型单位。
- 捕捉候选只取视野附近实体，1000 个图元时 pointermove 不卡。

### 4.3 数值输入

- 绘制时在光标附近显示 HUD。
- 支持格式：
  - `100`：线长 / 矩形宽 / 圆半径，取决于当前工具。
  - `100,50`：宽 × 高。
  - `100<30`：长度 100、角度 30°。
  - `@50,20`：相对上一点。
- Enter 确认，Esc 取消，Tab 在字段之间切换。
- 输入值直接决定最终几何，不依赖鼠标当前位置。

验收：

- 直线输入 `120<37`，导出 JSON 中端点距离和角度误差小于 1e-6。
- 矩形输入 `200,80`，四角坐标可复现。
- 圆输入 `R25` 或 `D50` 都得到同一半径。

### 4.4 选择与命中

- 点选、Shift 加减选、Esc 清空。
- 框选：左到右为窗口选择（完全包含），右到左为交叉选择（碰到即选）。
- 命中测试抽成 `hit.ts`，按图元类型和屏幕容差计算，不依赖 SVG 事件目标。
- 选中样式统一：主色描边 + 淡色光晕，和标注选择区分。

验收：

- 重叠图元能按 z-order 选中；框选方向和规则一致。
- 画布 2000 个图元时框选仍可用；不达标再考虑 canvas 叠加层，不提前重构。

## 5. P1：编辑能力

### 5.1 夹点编辑

- 直线：两个端点、中点。
- 矩形：四角、四边中点。
- 圆：圆心、四个象限点。
- 圆弧：起点、终点、弧中点。
- 路径：外轮廓顶点，孔洞顶点用不同颜色。

夹点拖动必须经过捕捉和正交逻辑。

### 5.2 属性面板

选中单个图元时显示可编辑数值：

- 通用：图层、颜色、线宽、锁定。
- 直线：起点/终点、长度、角度。
- 矩形：左上角、宽、高。
- 圆：圆心、半径、直径。
- 圆弧：圆心、半径、起止角。
- 路径：顶点数、包围盒、面积。

属性修改和夹点拖动走同一条「生成新几何」路径，避免两套语义。

### 5.3 编辑工具

按这个顺序做，前一个稳定后再做下一个：

1. **移动/复制/旋转/镜像/缩放**：全部支持数值输入。
2. **偏移**：直线、圆、矩形；路径偏移后做自交清理。
3. **修剪**：直线、圆、圆弧两两求交，剪掉选中段。
4. **延伸**：直线延伸到最近边界。
5. **圆角**：先只做直线-直线；半径可输入。
6. **分割/连接**：把路径拆成段、把首尾相接的段合成路径。

验收：

- 每个工具都有纯几何单元测试，不依赖浏览器。
- 修剪/延伸不产生零长度段和重复点。
- 圆角失败时保持原图元不变，并在状态栏说明原因。

## 6. P2：尺寸与轻约束

### 6.1 尺寸标注

先做参考尺寸，不改几何：

- 线性、水平、垂直、对齐。
- 半径、直径。
- 角度。
- 尺寸样式：箭头、延伸线、文字位置、单位。

然后把「可编辑尺寸」接到属性系统：改尺寸文字即改几何。

### 6.2 约束子集

第一版只做能被简单求解器稳定处理的：

- 水平、垂直。
- 重合、共线。
- 等长、等半径。
- 平行、垂直。
- 同心。
- 距离、角度。

求解顺序：

1. 推断约束：捕捉到端点时自动加重合；正交绘制时自动加水平/垂直。
2. 轻量求解：变量是端点/圆心/半径，使用带阻尼的 Gauss-Newton 或 Levenberg-Marquardt。
3. 失败回滚：不收敛就恢复拖动前状态，给出「约束冲突」提示。

暂不做：

- 参数化特征树。
- 装配约束。
- 完整草图求解器的所有约束组合。

验收：

- 10 个图元、20 个约束以内，拖动 60fps 或至少交互不阻塞。
- 过约束、冲突约束能明确报错，不静默改坏几何。

## 7. P3：DXF 交换

第一版只支持 ASCII DXF，保证可读可测：

导出：

- `LINE`、`CIRCLE`、`ARC`、`LWPOLYLINE`、`TEXT`。
- 图层表、颜色、线型（至少 CONTINUOUS）。
- 单位写入 `$INSUNITS`；默认毫米。
- 布尔路径按 LWPOLYLINE 输出，孔洞用多个闭合环。

导入：

- 识别上述实体和图层。
- 不支持的对象跳过并汇总提示，不阻塞整份导入。
- 导入后统一经过 `normalizeProject`，保证图层 ID 和坐标有效。

验收：

- 导出文件能在 FreeCAD 打开，圆的半径、圆弧方向、图层不丢。
- 导出再导入，图元数量、包围盒、图层名一致；允许坐标精度在 1e-6 内。

## 8. P4：仿真标注绑定

这是 SimSketch 和普通 CAD 的分水岭。

- 标注不再只存绝对点，而是增加锚点：

```js
{
  anchor: {kind: 'entity', entityId, param: 0.5}
}
```

或：

```js
{
  anchor: {kind: 'path', entityId, ring: 0, segment: 3, t: 0.5}
}
```

- 图元移动、变形、布尔替换时，标注跟随。
- 图元被删除时，标注标记为「失去锚点」，进入待处理列表，不静默删除。
- 区域标注可直接引用闭合路径，布尔结果变化后自动更新区域轮廓。
- 导出 JSON 保留锚点信息和失效状态。

验收：

- 移动图元后，箭头和文字仍贴在正确位置。
- 布尔替换后，区域标注仍指向新路径。
- 失去锚点的标注在侧栏可见、可重新绑定。

## 9. 代码边界

`app.ts` 已完成首轮拆分（editor/state、viewport、persistence、export 分离），后续 P0 新增能力继续按下列边界落位，不要重新堆回入口文件。

建议边界：

```text
viewport.ts        世界坐标 <-> 屏幕坐标、缩放、平移、适配
geometry.ts        图元类型、路径、包围盒、平移（保持纯函数）
kernel.ts          二维布尔 / 曲线离散 / 三角化 / 编辑操作的 Wasm 唯一门面
renderer.ts        SketchRenderer 契约与跨后端 RenderScene
renderer-host.ts   后端选择、WebGPU → Canvas2D → SVG 升级/回退
scene.ts           项目 → RenderScene 的纯数据映射
webgpu-renderer.ts 默认实时渲染
canvas2d-renderer.ts 兼容回退
svg-renderer.ts    SVG 回退与视觉对照（导出走 svg-document.ts → board.ts）
snap.ts            捕捉候选、优先级、阈值
hit.ts             命中测试与框选规则
editor.ts          指针状态机：绘制、拖动、夹点、框选
app.ts             只做 DOM、面板、文件、持久化和编辑器接线
board.ts           文字/标签 overlay 与 SVG 交互命中代理
project.ts         项目数据规范化与持久化
```

原则：

- 几何模块不读 DOM，不碰 `project`。
- `editor.ts` 只通过回调请求提交变更，不直接写 IndexedDB。
- 布尔结果必须保留 MultiPolygon 结构，禁止拍平成无归属的环。
- 新增图元类型先补几何测试，再接 UI。

## 10. 数据模型演进

现阶段保持 `shapes` 字段，减少迁移风险。下一次 schema 升级再统一为：

```js
{
  version: 2,
  units: {name: 'mm', scale: 1},
  layers: [],
  entities: [],
  annotations: [],
  reference: null
}
```

迁移规则：

- 旧 `shapes` -> `entities`，`type` 不变。
- 旧 `marks` -> `annotations`，保留绝对坐标，anchor 为空。
- 旧草稿默认 `units.name = 'px'`，用户设置毫米后再换算。
- `normalizeProject` 必须幂等，迁移后再次打开不重复改数据。

## 11. 测试与质量门

每个阶段必须同时交付：

- 纯几何单元测试：图元路径、交点、偏移、修剪、圆角、布尔不变量。
- 数据迁移测试：旧草稿、坏图层、坏锚点、版本升级。
- 浏览器冒烟：绘制、选择、布尔、导出、刷新持久化。
- 性能基线：500 / 2000 图元的加载、绘制、框选、捕捉耗时。

布尔测试额外要求：

- 随机矩形/圆组合做并、交、差，结果环必须闭合、无零面积碎片。
- 结果再次参与布尔，面积保持稳定。
- 退化输入（重合边、相切、完全包含）不能抛异常，失败要返回 null 并在 UI 说明。

## 12. 第一轮直接开工的顺序

建议按三个可独立验收的提交推进：

1. **抽出 `viewport.ts`**：滚轮缩放、空格平移、F 适配；现有绘制和导出行为不变。
2. **接 `snap.ts`**：端点、中点、圆心、栅格 + Shift 正交；捕捉标记和阈值换算。
3. **数值输入 HUD**：直线长度/角度、矩形宽高、圆半径；Enter 提交、Esc 取消。

这三个完成后，再决定 P1 先做夹点还是属性面板。此时才适合讨论「像不像 CAD」，因为画得准、改得准的基础已经有了。

## 13. 风险

- **范围膨胀**：约束求解器是另一个项目。P2 只做轻约束，不承诺完整参数化。
- **SVG 性能**：图元数量上来后先做分层缓存和离屏命中；达到 2000 图元再评估 canvas 叠加。
- **布尔精度**：圆和圆弧会拍平成多边形，阈值必须集中配置，不能散落在工具里。
- **移动端精度**：CAD 交互桌面优先；手机保留画和选，不强行塞满桌面级工具。
- **标注迁移**：P4 之前不要改标注坐标语义，否则旧草稿难以恢复。
