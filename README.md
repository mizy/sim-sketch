# SimSketch

用手指、触控笔或鼠标描述仿真里的受力区域、固定约束和方向。可以从空白画板开始，也可以导入图片后标注。支架示例可用于熟悉标注流程。

## 运行

在项目目录执行 `python3 -m http.server 18765 --bind 127.0.0.1`，访问 `http://localhost:18765/`。这是无构建依赖的静态项目，也可托管到 HTTPS 的静态站点或站点子目录。

应用首次加载后可离线打开和绘制，当前草稿使用 IndexedDB 保存到本设备。开始另一张草图或导入新图片前，可以导出当前草图的 PNG 或完整 JSON；同一次使用中的替换也可以撤销。打开应用的「安装应用」可看到系统安装入口。发布新版资源时更新 `sw.js` 中的缓存版本。

## AI 读图

在「模型设置」中填写支持图片输入且允许浏览器跨域请求的 OpenAI-compatible Chat Completions 完整地址、模型名和可选的密钥。服务端若提供同源代理，可填写其完整地址。密钥只留在当前页面内存中。点击「AI 读图」后发送草图和标注，用同一坐标系回显识别结果。点右侧标注可改类型、区域说明、载荷数值和模型方向，并确认结果。AI 结果中的区域使用画板坐标，实际求解器表面由用户确认。

## 入口

`index.html` 加载 `app.js`，由其组织绘制、草稿和读图交互。`board.js` 管理绘制和图片转换，`project.js` 管理草稿存储和标注数据，`vision.js` 负责模型请求与结果解析，`sw.js` 提供离线启动。

实时画板优先使用 WebGPU。`gpu-board.js` 接收相同的画板坐标，使用 WGSL 绘制点阵、笔画、圈选和箭头，并在 GPU 上合成参考图。SVG 负责文字、选择命中和导出，也用于 WebGPU 不可用时继续绘制。画板底部会显示当前渲染模式。
