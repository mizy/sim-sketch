# SimSketch

用手指、触控笔或鼠标描述仿真里的受力区域、固定约束和方向。可以从空白画板开始，也可以导入图片后标注。支架示例可用于熟悉标注流程。

## 运行

在项目目录执行 `python3 -m http.server 18765 --bind 127.0.0.1`，访问 `http://localhost:18765/`。这是无构建依赖的静态项目，也可托管到 HTTPS 的静态站点或站点子目录。

应用首次加载后可离线打开和绘制，当前草稿使用 IndexedDB 保存到本设备。可用「复制图片」将当前画布复制到剪贴板。开始另一张草图或导入新图片前，可以导出当前草图的 PNG 或完整 JSON；同一次使用中的替换也可以撤销。打开应用的「安装应用」可看到系统安装入口。发布新版资源时更新 `sw.js` 中的缓存版本。

在画布上选择标注，或打开「标注」列表，可修改类型、区域说明、载荷数值和模型方向。文字工具可直接在画布上输入；选择工具可拖动对象，双击文字或点击「编辑」继续修改。回车保存，Esc 取消；清空已有文字可删除该标注。打开「图层」可新建和重命名图层、调整顺序和不透明度；新对象加入当前图层，选中对象后可以更换所在图层。导入的参考图片也位于独立图层。

## 入口

`index.html` 加载 `app.js`，由其组织绘制和草稿交互。`board.js` 管理绘制和图片转换，`project.js` 管理草稿存储和标注数据，`sw.js` 提供离线启动。

实时画板使用 SVG 对每个图层整体合成，以保证图层透明度、顺序和导出一致；`gpu-board.js` 在可用时绘制画布底色和点阵。

「画笔颜色」支持自动、仿真预设和自定义颜色。选中预设后，新画的笔画、圈选、箭头和文字都会带上对应的语义。图例按画布上实际使用的颜色合并，并附在 JSON 中。
